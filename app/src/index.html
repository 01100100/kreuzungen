There was a bridge I couldn't cross alone, but the community built one together.

The Strava integration for Kreuzungen.world had stopped working.

Strava changed its API terms, so I needed to run a fundraiser to cover operating costs. Thanks to some amazing donors, we reached the goal and covered the costs. Now the dam is open. The rivers are still running, and Kreuzungen.world is flowing again.
